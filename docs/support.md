# Support

We help with questions about setting up and using the Stridecore theme, and fix bugs in the theme.

## Contact us

- **Issue tracker:** https://github.com/RJGJ/stridecore-theme/issues

Please include:

1. **Your store URL**, for example `your-store.myshopify.com`
2. **The theme version** (shown in the theme editor under **Theme settings** at the top, or in the file `config/settings_schema.json`)
3. **What went wrong and what you expected.** Steps to reproduce help a lot.
4. **A screenshot or screen recording** if you can.
5. **A preview link** if your store is password protected, or the password.

## Response time

We reply within two business days (Monday to Friday). Complex issues may take longer to resolve, and we will tell you where we are.

## What is covered

- Setting up and customizing the theme with the theme editor
- Bugs in the theme code
- Compatibility with new Shopify features we support

## What is not covered

- Custom code changes made by you or a third party
- Conflicts with third-party apps, though we will look at what we can fix in the theme
- Shopify platform features outside the theme, such as checkout, payments and apps. Shopify Support can help with those.

## Updates

Release notes for every version are in the [changelog](../CHANGELOG.md).
