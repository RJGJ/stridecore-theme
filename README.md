# Stridecore

A bold, high-contrast Shopify theme for sports apparel and streetwear stores. Built for Online Store 2.0 with original code.

## Develop

```bash
yarn install
yarn dev --store your-store.myshopify.com
yarn lint
yarn package
```

Copy `.env.example` to `.env.local` for store tooling credentials. Never commit `.env.local`.
